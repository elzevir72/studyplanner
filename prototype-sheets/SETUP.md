# Sheets 프로토타입 셋업 가이드

목적: AWS 버전을 만들기 전에, "다들 꾸준히 기록하고 공유하는지"부터 Google Sheets로 빠르게 실증한다. 여기서 확인된 데이터 필드/미수행자 판정 기준은 나중에 [`../docs/data-model.md`](../docs/data-model.md), [`../docs/architecture.md`](../docs/architecture.md)에 반영한다.

## 1. 스프레드시트 가져오기
1. Google Sheets에서 새 스프레드시트 생성.
2. 파일 → 가져오기 → 업로드 → `study_planner_prototype.xlsx` 선택 → **"새 스프레드시트로 바꾸기"** 선택.
3. `Config` / `Entries` / `Dashboard` 3개 탭이 그대로 들어온다.
4. `Config` 탭에서 `참가자1~10` 이름을 실제 그룹원 이름으로 바꾸고, 안 쓰는 행은 `활성`을 `FALSE`로 두거나 이름을 지운다.

수식이 가져오기 과정에서 깨졌다면(`#NAME?` 등), 아래 "2. 수식이 안 먹을 때"를 참고해 다시 붙여넣는다.

## 2. 수식이 안 먹을 때 (fallback)
`Dashboard` 탭 수식은 Google Sheets 전용 함수(`ARRAYFORMULA`, `QUERY`, `TEXTJOIN`)를 쓰기 때문에 xlsx 가져오기 중 깨질 수 있다. 깨진 셀은 아래 표대로 다시 입력한다 (예: 9행 = 참가자1행 기준).

| 셀 | 수식 |
|---|---|
| `B4` | `=B3-WEEKDAY(B3,3)` |
| `B5` | `=B4+6` |
| `B9` (기록 수) | `=COUNTIFS(Entries!$B:$B,$A9,Entries!$C:$C,">="&$B$4,Entries!$C:$C,"<="&$B$5)` |
| `C9` (목표 달성 수) | `=COUNTIFS(Entries!$B:$B,$A9,Entries!$C:$C,">="&$B$4,Entries!$C:$C,"<="&$B$5,Entries!$H:$H,TRUE)` |
| `D9` (상태) | `=IF($A9="","",IF(B9=0,"⚪ 미기록","✅ 기록함"))` |
| 미기록자 목록 | `=TEXTJOIN(", ",TRUE,ARRAYFORMULA(IF(($A$9:$A$18<>"")*($B$9:$B$18=0),$A$9:$A$18,"")))` |
| 최근 공유 메모 | `=QUERY(Entries!A:I,"select C,B,I where I != '' order by C desc limit 15",1)` |

9행 수식을 10~18행에 복사-붙여넣기하면 셀 참조(`$A9`→`$A10` 등)가 자동으로 따라간다. 월간 섹션(27행 이하)도 동일한 방식이고, 날짜 범위만 `$B$24`/`$B$25`를 참조한다.

## 3. 입력 방법 — Google Form 연결 (권장)
실제 앱의 "드롭다운에서 사용자 선택 후 기록"과 가장 비슷한 경험을 만들려면 Form을 붙인다.

1. Google Form 새로 생성, 질문을 `Entries` 탭 컬럼 순서와 맞춰 추가:
   - **이름** — 드롭다운, 선택지는 `Config` 탭의 이름과 동일하게 수동 입력
   - **학습일자** — 날짜
   - **학습수단** — 단답형 (예: 인강, 문제집)
   - **학습내용** — 단답형 (예: 문법, 어휘)
   - **학습량_숫자** — 단답형 (숫자)
   - **학습량_단위** — 단답형 (예: 단어, 페이지)
   - **목표달성** — 객관식 (TRUE/FALSE)
   - **메모** — 장문형
2. Form의 응답(Responses) → 스프레드시트 아이콘 → **기존 스프레드시트 선택** → 이 파일을 지정.
3. 응답이 쌓이는 시트가 자동 생성되면(보통 `설문지 응답 시트1`), 원래 만들어둔 `Entries` 탭 대신 그 시트를 쓰거나, `Entries` 탭 이름과 동일하게 바꾸고 `Dashboard` 수식의 시트명 참조도 맞춰준다.
4. Form 링크를 그룹원에게 공유. Form은 로그인 없이도 응답 가능하도록 설정할 수 있어("설정 → 로그인 필요" 해제), 계정 없는 "이름 선택 후 기록" 흐름을 그대로 재현할 수 있다.

## 4. 공유 설정
- **입력**: Form 링크 공유 (로그인 불필요 설정 시 누구나 이름만 골라 기록).
- **대시보드 열람**: 스프레드시트 자체는 "링크가 있는 모든 사용자 - 뷰어"로 공유해 그룹원 모두 `Dashboard` 탭을 볼 수 있게 하되, 실수로 데이터를 건드리지 않도록 편집 권한은 주지 않는다.

## 5. 무엇을 검증할지
- 그룹원들이 실제로 며칠/몇 주 꾸준히 기록하는지 (도구 문제가 아니라 습관 문제인지 구분)
- `학습수단`/`학습내용` 자유 입력 태그가 실제로 어떤 값들로 채워지는지 → 나중에 프리셋 태그 목록을 만들 때 참고
- "이번 주 기록 0건 = 미기록"이라는 기준이 실제로 동기부여가 되는지, 아니면 다른 기준(연속 일수 등)이 필요한지
- `Dashboard`가 보여주는 정보량이 충분한지, 부족한지

2~3주 정도 운영해보고 결과를 공유하면, 그 관찰을 바탕으로 AWS 버전 설계(`../docs/data-model.md`)를 다시 조정한다.
